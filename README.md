# Wasel Chat — واصل شات

مشروع مراسلة ويب عربي يدعم:
- إنشاء حساب وتسجيل الدخول.
- البحث عن مستخدم باسم المستخدم.
- طلب محادثة عادية وقبولها قبل بدء الرسائل.
- إرسال واستقبال الرسائل الفورية عبر Socket.IO.
- صندوق رسائل مجهولة يمكن للمستخدم تشغيله أو إيقافه.
- الحظر والإبلاغ.
- لوحة مشرف للإحصائيات ومراجعة البلاغات.

## التشغيل
المتطلبات: Node.js 20+.

1. فك الضغط وافتح مجلد المشروع في محرر يدعم Terminal.
2. انسخ `.env.example` إلى `.env`.
3. غيّر `SESSION_SECRET` إلى سر عشوائي طويل (32 حرفاً على الأقل) وغيّر `ADMIN_PASSWORD`.
4. نفّذ:
   ```bash
   npm install
   npm start
   ```
5. افتح `http://localhost:3000`.
6. لوحة الإدارة: `http://localhost:3000/admin.html`.

## التشغيل من الموبايل/التابلت
الأسهل للمبتدئ: ارفع الملفات إلى GitHub كمستودع خاص، وافتحه في GitHub Codespaces من المتصفح إن كانت الخدمة متاحة لحسابك. افتح الطرفية، نفّذ `npm install` ثم `npm start`، وافتح المنفذ 3000 من تبويب Ports. ضع الأسرار في Environment/Secrets ولا ترفع `.env`.
التشغيل المحلي على Android قد يتطلب بيئة Node متوافقة مع مكتبة SQLite؛ لذلك Codespaces غالباً أبسط.

## الاستخدام
- أنشئ حسابين تجريبيين باسمين مختلفين في متصفحين أو نافذتين خاصتين.
- من الحساب الأول ابحث عن اسم الحساب الثاني وأرسل طلب محادثة.
- سجّل الدخول بالحساب الثاني واقبل الطلب.
- ارجع للأول وابدأ تبادل الرسائل.
- جرّب الرسائل المجهولة من نتائج البحث أو شارك رابط الصندوق من تبويب المجهول.
- أوقف استقبال المجهول من الإعدادات.
- اختبر الحظر والإبلاغ من داخل المحادثة.

## لوحة الإدارة
أنشئ حساب المشرف تلقائياً عند بدء الخادم من `ADMIN_USERNAME` و`ADMIN_PASSWORD` في `.env`. افتح `/admin.html` وسجّل الدخول.

## الملفات
- `server.js`: Express API، Socket.IO، الجلسات، قاعدة البيانات.
- `public/index.html`: واجهة المستخدم.
- `public/styles.css`: التصميم المتجاوب.
- `public/app.js`: منطق الواجهة.
- `admin.html`: لوحة المشرف.
- `data/`: قاعدة البيانات والجلسات (تُنشأ تلقائياً).
- `.env.example`: مثال إعدادات البيئة.

## الأمان والخصوصية
الرسائل المجهولة تخفي اسم المرسل عن المستلم فقط؛ يحتفظ الخادم بمعرف المرسل لمكافحة الإساءة والتعامل مع البلاغات. لا تصف الخاصية بأنها مجهولة تماماً أو غير قابلة للتتبع.
توجد كلمات مرور مجزأة بـ bcrypt، جلسات محفوظة في SQLite، ملفات تعريف ارتباط HttpOnly وSameSite، تحديد معدل لمحاولات الدخول والرسائل المجهولة، طلب قبول للمحادثات، حظر وإبلاغ، وحدود لطول الرسائل.

## حدود النسخة MVP
لا يوجد حالياً: تحقق بريد، استعادة كلمة المرور، صور وملفات، مكالمات، مجموعات، إشعارات Push، أدوات تعليق الحسابات أو حذف المحتوى، مراجعة آلية، أو حماية CSRF متقدمة. لا تعتبر هذه النسخة جاهزة لاستقبال الجمهور على نطاق واسع.

## قبل النشر العام
- استخدم HTTPS واضبط `COOKIE_SECURE=true` و`NODE_ENV=production`.
- ضع الأسرار في إعدادات الاستضافة وليس GitHub.
- أضف حماية CSRF واختبارات أمنية مستقلة ومراجعة للكود.
- أضف سياسة خصوصية وشروط استخدام وسياسة احتفاظ وحذف للبيانات.
- جهّز آلية إشراف فعالة وبلاغات واستجابة للحالات العاجلة.
- اختبر النسخ الاحتياطي، الاستعادة، وتحمل الضغط.
- اجمع أقل قدر ممكن من بيانات المستخدمين.
- لا ترفع `.env` أو `data/` أو `node_modules/` إلى GitHub.
